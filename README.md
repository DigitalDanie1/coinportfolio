# 코인 포트폴리오 · 자동 데이터 업데이트

기존 `index.html`을 새로고침하면 로컬 데이터 서비스에 연결됩니다. 기존 브라우저와 파일 주소를 유지하면 보유 기록과 Thesis·Conviction도 유지됩니다. `http://127.0.0.1:8787`로 새로 열면 브라우저 저장소가 다른 출처이므로 기존 파일 페이지의 기록은 자동으로 이전되지 않습니다.

## 실행

`start.command`를 실행하거나 이 폴더에서 `node server.mjs`를 실행합니다. Node.js 20.11 이상이 필요합니다. 서비스는 `127.0.0.1:8787`에서만 수신합니다. 컴퓨터를 재시작하거나 서비스를 종료했다면 다시 실행해야 합니다. 별도 패키지 설치는 없습니다.

페이지가 열려 있는 동안 시세·옵션 현재가·PERP 시장 정보·연결된 계좌를 1분 간격으로 갱신합니다. 뉴스는 15분 간격입니다. 숨긴 페이지는 새 요청을 멈추고 돌아왔을 때 갱신합니다. 실패 시 30초부터 최대 5분까지 재시도 간격을 늘리며, 이전 값과 저장 데이터 표시를 유지합니다. `지금 갱신`은 즉시 갱신을 요청하되 제공자 캐시와 요청 제한은 준수합니다.

## 자동 연결되는 데이터

| 데이터 | 제공자 / 동작 |
|---|---|
| 코인 ID·공식 명칭·티커 | CoinGecko 목록의 정확한 프로젝트 식별, 필요 시 CoinPaprika |
| 시세·24시간 변동·마켓캡·로고·7일 차트 | CoinGecko, 장애 시 CoinPaprika 대체 데이터. 대체 차트는 일별 시계열이며 출처 표시 |
| USD 상장 주식 가격·차트 | Yahoo Finance 공개 차트 응답, 주식 변동률은 전일 대비. 비공식 엔드포인트로 응답이 제한될 수 있음. 로고·마켓캡이 없는 응답은 추정하지 않음 |
| News | Google News RSS, 최근 7일 최대 8개 기사. 제목·출처·발행 시각·원문 링크 표시 |
| 옵션 현재가·승수·IV·Greeks | Deribit 공개 API. 거래소가 Deribit이고 기초자산·만기·행사가·Call/Put이 정확히 일치하는 계약. USD 프리미엄은 현물 index_price로 환산 |
| PERP 마크 가격·시간당 펀딩 | Hyperliquid 공개 시장 API |
| PERP 계좌 포지션·수량·진입가·증거금·레버리지·청산가·미실현 손익 | `자동 연결`에서 입력한 Hyperliquid 공개 계좌 주소를 읽기 전용 API로 조회 |

Thesis·Conviction은 브라우저에 별도로 보존하며 자동 동기화 응답으로 덮어쓰지 않습니다. 뉴스·시세 API에는 종목 식별 정보만 전송하고 Thesis, Conviction, 수량, 진입가는 전송하지 않습니다. Hyperliquid 계좌 연결을 설정하면 입력한 공개 주소만 해당 계좌 조회 API에 전달합니다.

## 연결 정보가 필요한 항목

- 같은 티커를 쓰는 밈코인은 임의로 선택하지 않습니다. `자동 연결`의 `종목 식별 필요`에서 정확한 프로젝트를 한 번 선택하면 이후 자동 갱신됩니다. 검색 결과가 없는 토큰은 컨트랙트 주소 또는 정확한 식별자가 필요합니다.
- 다른 거래소의 보유 수량·진입가, 주식 계좌, Deribit/Derive 등의 실제 옵션 보유 포지션은 계좌 연결이 필요합니다. 이 버전의 계좌 자동 수집은 Hyperliquid PERP만 지원합니다. 옵션의 공개 시세 연동과 개인 계좌의 보유 포지션 수집은 서로 다른 기능입니다.
- Farming의 누적 수수료·확정 보상·미확정 포인트는 해당 계좌/프로토콜 소스가 없으면 `미입력` 또는 `미연결`로 둡니다. Hyperliquid 연결 포지션의 손익은 거래소가 제공한 미실현 손익이며, 수수료·보상·포인트를 추정하거나 합산하지 않습니다.
- 자동 시세가 없는 옵션은 기존 수동 기록을 유지하며 상태를 표시합니다. 자동 만기 정산은 하지 않습니다.
- CoinGecko가 로고만 제공하고 가격이나 차트를 제공하지 않는 종목은 가능한 메타데이터만 표시합니다.
- Farming·옵션은 현물 자산 합계에 포함하지 않습니다. 연결 계좌의 종료된 포지션은 숨기되 Thesis·Conviction은 기록에 보관합니다.

## 파일 및 검증

- `server.mjs`: 로컬 HTTP/API 서비스. 고정된 제공자만 호출하고 임의 URL 프록시는 제공하지 않습니다.
- `lib/data-service.mjs`: 제공자 어댑터, 종목 식별, 캐시, 오류 시 저장 데이터 유지.
- `auto-sync.js`: 자동 주기, 기사 표시, 포지션 병합, 연결 UI.
- `.data/public-cache.json`: 공개 시장 데이터 캐시. 계좌 API 결과는 이 파일에 저장하지 않습니다.
- 브라우저의 `coin-portfolio-v2`에 기존 보유 데이터·Thesis·Conviction을 유지합니다.

```sh
node tests/position-tools.test.cjs
node --test tests/data-service.test.mjs
node tests/auto-sync.test.cjs
```

자동 동기화·Thesis/Conviction 보호·옵션 통화 환산·계좌 포지션 병합·캐시/백오프·기사 파싱을 검증합니다. 로컬 파일에 대한 브라우저 도구 접근이 차단되어 화면 자체의 시각 검증은 수행하지 않았습니다. 로컬 API의 실제 시세·뉴스·옵션·PERP 수신은 별도로 검증했습니다.

참고: [CoinPaprika 시계열 API](https://docs.coinpaprika.com/api-reference/tickers/get-historical-ticks-for-a-specific-coin), [Deribit 시장 데이터](https://docs.deribit.com/api-reference/market-data/public-get_book_summary_by_currency), [Hyperliquid PERP API](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/perpetuals).

## 시나리오와 전체 차트

- 상단 **나의 시장 시나리오**는 여러 자산의 예상 흐름, 목표, 조정 구간, 무효화 조건을 자유롭게 쓰는 칸 하나입니다. 입력 즉시 브라우저에 저장되며 자동 시세·계좌 동기화가 내용을 변경하지 않습니다. 첨부 예시의 과거 목표 가격은 자동으로 입력하지 않았습니다.
- 표의 작은 차트를 클릭하면 큰 차트 창이 열립니다. CoinGecko에서 확인한 거래소 페어를 TradingView 위젯에 연결하고, 확인된 토큰 컨트랙트로 DEX Screener 페어를 찾아 소스 선택에 추가합니다. DEX 페어는 일반적인 결제 토큰, 거래량, 유동성을 기준으로 정렬합니다.
- 차트 창에는 항상 외부 TradingView/DEX Screener 링크도 제공합니다. 위젯이 해당 심볼을 지원하지 않거나 브라우저가 iframe을 제한하면 외부 링크로 열 수 있습니다.
- 종목 식별이 불확실한 경우 다른 코인의 차트를 임의로 띄우지 않습니다. `자동 연결`에서 정확한 자산을 지정해야 합니다.

차트 참고: [TradingView Advanced Chart](https://www.tradingview.com/widget-docs/widgets/charts/advanced-chart/), [DEX Screener API](https://docs.dexscreener.com/api/reference).

### 사용자 DEX 링크 (2026-09-18)

`dex-imports.js`에 검증된 12개 페어(13개 입력 중 중복 1개)를 저장했습니다. 다음 페이지 새로고침에 기존 Prologue(`prlg`)와 HyperEVM PURR(`purr-hev`)를 연결하고 나머지 10개를 포모·밈에 추가합니다. Solana Hypurr/PURR는 별도 종목이며 기존 Robinhood PURR와 합치지 않습니다. 이름이나 티커가 같다는 이유로 다른 자산에 연결하지 않습니다.

가져오기는 저장 데이터의 `appliedImports`로 한 번만 실행합니다. 기존 보유 수량·평단·Thesis·Conviction과 시나리오·회고는 유지하고, 연결이 바뀐 두 종목의 이전 자동 시세/뉴스 캐시는 제거합니다. 이후 삭제한 종목은 새로고침해도 되살아나지 않습니다.

DEX Screener의 정확한 체인·풀·토큰 주소로 USD 가격, 로고, 24시간 변동, 거래량, 유동성, 시가총액을 1분 주기로 갱신합니다. FDV는 시가총액으로 대체하지 않습니다. 지정한 풀이 응답하지 않아도 동명 토큰으로 자동 변경하지 않습니다. 차트 클릭 시 지정한 풀의 DEX Screener 차트를 엽니다.

이 API는 7일 과거 가격을 제공하지 않으므로 DEX의 미니 차트는 **연결 이후 수집 기록**입니다. 서비스에 타임스탬프와 관측 가격을 저장하며 관측치가 2개 이상 쌓이면 표시합니다. 앱이 열린 동안 자동 갱신한 기록만 수집하며 미접속 구간을 과거 데이터로 채우지 않습니다. TradingView/DEX 임베드가 공급자 측에서 차단되면 모달의 외부 차트 링크를 사용할 수 있습니다.

### DEX PERP 페어 작업 공간

`farming-pairs.js`는 `farmingPairs`를 기존 저장 데이터에 추가하며 첫 실행에 빈 3개 페어를 만듭니다. 각 페어는 같은 기초자산의 롱 거래소와 숏 거래소를 설정합니다. 실제 거래소 6곳은 아직 지정되지 않았습니다. 이름, 수량, 마크, 7일 획득 포인트, 같은 기간 순비용, 집계 종료일, 공식 규칙 URL, 전략, Thesis, Conviction을 편집할 수 있습니다. 거래 주문을 실행하지 않습니다.

기존 `farming` 포지션은 유지됩니다. `positionId`로 연결하면 계좌의 방향·수량·상태를 사용하고 Hyperliquid 마크는 공개 피드에서 갱신합니다. 다른 페어에서 사용 중인 포지션, 다른 기초자산, 잘못된 방향은 연결할 수 없습니다. 연결 포지션이 종료되거나 누락되면 순노출 계산을 중단합니다. 수동 수량·포인트·비용은 연결 API가 생기기 전까지 사용자가 기록해야 합니다.

순수량은 롱 수량 − 숏 수량, 수량 차이는 절댓값 / 큰 쪽 수량입니다. 선형 PERP의 기초자산 단위에만 적용합니다. 서로 다른 거래소의 마크로 총 명목가치를 계산하며, 수량 균형을 무위험으로 표시하지 않습니다. 7일 순비용은 수수료 + 슬리피지 + 지급 펀딩 − 수취 펀딩으로 기록합니다. 포인트당 비용은 순비용 / 획득 포인트이며 미입력 또는 포인트 0은 계산하지 않습니다. 서로 다른 프로그램의 포인트를 합산하거나 수익으로 환산하지 않습니다. 공식 프로그램이 확인되기 전에는 최대 포인트 전략이나 적립률을 추정하지 않습니다.

검증: `node tests/farming-pairs.test.cjs`.
